# Vibecoder 사용 안내

Vibecoder는 AI와 대화하며 프로그램을 만드는 Windows 앱입니다. Claude 또는 Codex 계정으로 연결해 사용합니다.

## 처음 시작하기

1. 사용할 AI를 고르고, 설치가 필요하면 앱 안의 **설치** 버튼을 누르세요. Codex는 ChatGPT 계정으로 연결합니다.
2. **계정 등록**에서 서비스와 구분할 이름을 입력하세요. 등록한 계정의 **로그인**을 눌러 브라우저에서 연결하세요. Claude 인증 코드가 표시된 경우에만 앱에 입력하면 됩니다. AI API 키는 사용하지 않습니다.
3. 프로젝트를 저장할 폴더를 선택하세요. AI 모델 같은 세부 설정은 기본값으로 시작해도 됩니다.

## 새 프로그램 만들기

1. **새로 만들기**를 누르세요.
2. 만들고 싶은 것을 평소 말하듯 적으세요. 예: “동호회 회비를 기록하고 월별 합계를 보여주는 웹 페이지를 만들어 줘.”
3. 제안을 받을 AI와 이 프로젝트에서 사용할 계정을 선택하고, 저장할 폴더를 고른 뒤 **만드는 방법 제안받기**를 누르세요.
4. 제안을 확인한 뒤 **이대로 만들기**를 누르세요. 필요한 도구 설치와 파일 준비가 진행되고 첫 대화가 시작됩니다.

이미 작업하던 폴더가 있다면 **기존 폴더 열기**로 등록하세요. 프로젝트 목록에서 제거해도 실제 폴더는 삭제되지 않습니다.

## 프로젝트마다 다른 계정 사용하기

1. **설정 → 계정**에서 사람이나 용도별로 계정을 등록합니다. 예: “민수 Claude”, “지수 Codex”, “팀 GitHub”.
2. 프로젝트 이름 옆 **⋯ → 사용할 계정 선택**에서 Claude Code·Codex·GitHub 계정을 각각 고르고 저장합니다. **새 대화** 화면에서도 선택할 수 있습니다.
3. 대화 상단에 표시된 계정 이름을 확인하고 작업합니다. GitHub 업로드·내려받기는 해당 프로젝트에 선택된 GitHub 계정을 사용합니다.

같은 계정을 여러 프로젝트에서 선택할 수도 있습니다. 계정을 선택하지 않으면 PC의 기존 로그인으로 대신 실행하지 않습니다. 기존 프로젝트도 계정을 선택해야 합니다.

계정 변경은 **새 대화**부터 적용됩니다. 이미 만든 대화는 시작할 때의 계정으로 이어집니다. 기존 공통 로그인으로 만든 대화는 기록을 열람할 수 있으며, 새 계정을 연결한 뒤 새 대화로 작업하세요.

GitHub는 등록한 계정에 접근 토큰을 연결합니다. 토큰은 Windows 자격 증명 관리자에 저장합니다. Git 커밋에 표시할 이름과 이메일은 프로젝트 계정 화면의 **Git 커밋 작성자 설정**에서 지정할 수 있습니다.

계정별 로그인 정보는 이 Windows 사용자의 앱 저장소에 보관되며 프로젝트 폴더나 Git에 기록하지 않습니다. 프로젝트나 대화에서 사용 중인 계정은 삭제할 수 없습니다.

## AI와 대화하기

- **새 대화**에서 원하는 작업을 적거나, 기존 대화를 선택해 이어서 요청하세요.
- Enter는 보내기, Shift+Enter는 줄바꿈입니다.
- 작업 중에도 **추가 요청**으로 방향을 바꿀 수 있습니다. **멈추기**는 현재 작업을 중단합니다.
- 다른 대화를 오가거나 미리보기를 열어도 작성 중인 초안은 유지됩니다. 앱을 종료하거나 화면을 다시 불러오면 전송하지 않은 초안은 사라집니다.
- 전송에 실패하면 입력 내용을 그대로 두므로 다시 보낼 수 있습니다.
- **대화 설정**에서 AI 모델과 작업 확인 방식을 바꿀 수 있습니다. **AI에게 맡기기**는 파일 수정과 프로그램 실행을 확인 없이 진행합니다.

## 결과 확인과 되돌리기

- **미리보기** → **미리보기 시작**으로 웹 화면을 확인하세요. **화면 선택**을 누르고 바꾸고 싶은 부분을 선택하면 대화 입력창에 추가됩니다.
- 미리보기는 웹 화면이 있는 프로젝트에서 사용합니다. 실행 명령을 자동으로 찾지 못하면 **실행 설정**을 확인하거나 AI에게 실행 방법을 물어보세요.
- **변경 내역**에서 수정한 파일을 확인하고 설명을 적어 **버전 저장**을 누르세요. 이 작업은 컴퓨터 안에 변경 기록을 저장합니다. 온라인에 올리기는 별도 작업입니다.
- **복원 지점**에서 AI가 작업하기 전의 상태를 확인하고 되돌릴 수 있습니다. 되돌리기 전 확인 화면에서 영향을 확인하세요.

## 문제가 생겼을 때

- 작업 공간이나 대화 기록을 불러오지 못하면 **다시 시도**를 누르세요.
- 프로젝트 만들기에 실패하면 **오류 자세히 보기**와 **실행 기록 자세히 보기**에서 원인을 확인하세요. 설정을 바꾸거나, 일부 만들어진 폴더를 **기존 폴더 열기**로 열어 이어서 작업할 수 있습니다.
- AI 연결이나 도구 설치 상태는 **설정**의 **계정**, **도구**에서 확인하세요.
- 파일 목록과 개발자 터미널은 상단 **더 보기**에 있습니다.
